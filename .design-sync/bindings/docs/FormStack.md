# FormStack

The vertical form column used by the landing and join forms: hint, inputs, gold CTA, divider, actions, error line.

```tsx
<FormStack>
  <FieldHint>…</FieldHint>
  <TextInput placeholder="Your name" />
  <Button block>Create Game</Button>
  <OrDivider />
  <ErrorMsg />
</FormStack>
```
