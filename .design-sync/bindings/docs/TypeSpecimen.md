# TypeSpecimen

The type system: EB Garamond (`var(--font-family-heading)`) for screen/section headings, Inter (`var(--font-family-base)`) for body and UI, Rye + Yellowtail only inside the vintage lobby stamp.

Headings: `<h1 className="screen-title">` (EB Garamond, large). Body: Inter at ~1rem with `--color-text-warm`. Button labels: Inter 700 with 0.05em letter-spacing. Never use Rye/Yellowtail outside stamp-styled artwork.
