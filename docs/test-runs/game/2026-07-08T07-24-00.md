## Notes

- **Environmental (not code regressions), all previously flagged:**
  - `WEBAUTHN_RP_ID` defaults to `tensies.app` in `docker-compose.yml`, so the CDP virtual authenticator on `localhost` is rejected ("relying party ID is not a registrable domain suffix"). Ran the auth ceremony after recreating `web` with `WEBAUTHN_RP_ID=localhost`. Worth an `.env`/compose note for local auth testing.
  - `.env.prod` still lacks `JWT_SECRET`, `WEBAUTHN_RP_ID`, `WEBAUTHN_ORIGIN` (prod compose marks them required). Supplied inline for the smoketest. (Prior-run watch item, still open.)
  - **Postgres volume password mismatch when switching dev↔prod stacks:** the two stacks use different `POSTGRES_PASSWORD`, and Postgres only sets the password on first init of an empty volume, so the shared `tensies_pg_data` volume authenticates for whichever stack initialized it. Both the dev→prod switch (Step 30) and the prod→dev restore (Step 34) required `down -v`. This is the single most time-consuming gotcha in the suite.
- **View-Transition context loss on round win.** Long promise-based `browser_evaluate` calls that span a round-win (`showScreen`'s View Transition) error with "Execution context was destroyed" — the page context survives (`_state` intact), only Playwright's long-promise binding is lost. Worked around by installing fire-and-forget window recorders/rollers and polling them with short evaluates (Steps 13, 22, 33). Do NOT read this as a game reload.
- **dpr limitation:** `browser_resize` sets CSS width/height (390×844) but not device-scale-factor, so `window.devicePixelRatio` stays 1. Layout/media-queries are correct; screenshots just raster at 1× rather than the harness's 2×.
- Overlay open-windows were remarkably tight this run: 2988–3041 ms across 15 recorded overlays (server `ROUND_WIN_DELAY = 3 s`).
